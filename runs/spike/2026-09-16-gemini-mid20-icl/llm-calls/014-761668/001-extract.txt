- Software Product: A legitimate software program, application, operating system, or utility used for computational tasks or system administration. (also: Software Application, Software Tool)

- exploits: Indicates that an entity takes advantage of a specific security vulnerability.
- hosts: Indicates that network infrastructure or a domain stores and serves a file or service.
- delivers: Indicates that a file, program, or channel drops, downloads, or installs a payload.
